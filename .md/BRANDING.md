# SURgul Brand Guidelines

**Official Name:** SURgul
**Pronunciation:** "SUR-gul" (rhymes with "surgical")
**Thai:** เซอร์เกิล

---

## Name Origin

**SURgul** = **S**afety-first **U**niversal **R**isk **G**overnance **L**ogic

The name emphasizes:
- **"SUR"** = Surgical precision + Safety-first approach
- **"gul"** = Governance + Logic
- **Pronunciation** = User-friendly, memorable, professional

---

## Typography

### Correct Usage ✅
- **SURgul** (preferred - CamelCase with capital SUR)
- SURgul (all lowercase for code/packages)
- **SURgul™** (with trademark when appropriate)

### Incorrect Usage ❌
- ~~SURGUL~~ (all caps - too aggressive)
- ~~Surgul~~ (only first letter capital - looks generic)
- ~~Sur-gul~~ (with hyphen - breaks pronunciation)
- ~~SurGul~~ (wrong capitalization)

## Voice & Tone

### Brand Personality
- **Professional** - Medical AI demands seriousness
- **Transparent** - Honest about limitations
- **Safety-first** - Patient protection is paramount
- **Approachable** - User-friendly name and documentation

### Communication Style

**Do:**
- Be direct and honest about capabilities
- Acknowledge limitations upfront
- Use plain language (avoid jargon when possible)
- Emphasize safety guarantees

**Don't:**
- Oversell or exaggerate performance
- Hide limitations in fine print
- Use marketing hype for medical software
- Make promises about clinical outcomes
